# Concepto de Diseño: Portfolio de Desarrollo Web

## Enfoque Seleccionado: Futurismo Técnico Minimalista

### Filosofía de Diseño
**Movimiento de Diseño**: Futurismo técnico con influencias de diseño de circuitos y geometría hexagonal. Inspirado en el patrón proporcionado que combina elementos de red neural, circuitos electrónicos y arquitectura modular.

### Principios Centrales
1. **Geometría Angular y Hexagonal**: Uso de formas hexagonales, líneas diagonales y ángulos agudos para reflejar la naturaleza técnica del desarrollo web
2. **Minimalismo Inteligente**: Espacios en blanco generosos combinados con elementos visuales estratégicos que no saturan
3. **Conexión Visual**: Líneas conectoras sutiles que sugieren flujo de datos y relaciones entre conceptos
4. **Profundidad Estratégica**: Capas visuales que crean dimensión sin comprometer la claridad

### Filosofía de Colores
- **Paleta Principal**: Verde azulado oscuro (#1a5f5f) como color primario, combinado con tonos beige/crema (#e8e4d9) como fondo
- **Acentos**: Líneas en verde más claro (#2d8a8a) para elementos interactivos
- **Razonamiento Emocional**: El verde azulado transmite confianza, tecnología y estabilidad; el beige evoca sofisticación y profesionalismo sin frialdad

### Paradigma de Layout
- **Asimétrico y Modular**: Evitar grillas centradas uniformes
- **Secciones con Clipping**: Usar clip-path para crear bordes angulares que reflejen el patrón de circuitos
- **Flujo Vertical con Pausas**: Espacios visuales que permiten respirar entre secciones
- **Elementos Flotantes**: Hexágonos y formas geométricas que parecen flotar en el espacio

### Elementos Distintivos
1. **Hexágonos Animados**: Formas hexagonales que aparecen, se conectan y animan en hover
2. **Líneas de Conexión**: Líneas SVG sutiles que conectan elementos y sugieren relaciones
3. **Bordes Angulares**: Clip-path con ángulos de 45° para crear marcos y secciones

### Filosofía de Interacción
- **Animaciones Fluidas**: Transiciones suaves que revelan contenido gradualmente
- **Feedback Visual**: Elementos que responden al hover con cambios de color y escala
- **Revelación Progresiva**: Contenido que aparece conforme el usuario desplaza la página

### Animaciones
- **Entrada de Secciones**: Fade-in con desplazamiento ligero (translateY)
- **Hover en Tarjetas**: Escala suave (1.02) con sombra aumentada
- **Líneas Animadas**: Stroke-dasharray para animar líneas SVG
- **Elementos Flotantes**: Animación de flotación sutil en hexágonos y formas

### Sistema Tipográfico
- **Display Font**: Playfair Display (serif elegante) para títulos principales - transmite sofisticación
- **Body Font**: Source Sans Pro (sans-serif limpia) para contenido - máxima legibilidad
- **Jerarquía**: Títulos grandes y audaces (48-64px), subtítulos medianos (24-32px), cuerpo legible (16-18px)
- **Pesos**: Usar 700 para títulos, 600 para énfasis, 400 para cuerpo

---

## Decisión Final
Se implementará el **Futurismo Técnico Minimalista** con énfasis en geometría hexagonal, líneas conectoras y animaciones sutiles que reflejen la naturaleza técnica del desarrollo web. La paleta de colores será verde azulado + beige, creando un ambiente profesional y moderno.
